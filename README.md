# Flight Data Visualisation Application 

## Overview 
An interaction Java application developed using Processing to visualise flight data. The application allows users to search and filter flight information, explore airports across the US and interact with a geographical heatmap. 

## Features 

### Flight Search and Filtering 
- Load and process flight information from a CSV dataset
- Filter flights by departure status (on time, delayed or cancelled)
- Search for flights by origin airport
- Filter flights by airline and flight number
- Search for flights within specified date range
- Combine multiple filters to narrow down results
- Browse flight results using scroll bar

### Interactive Airport Heatmap 
- Visualise the number of airports in each US state
- Display airport counts when hovering over individual states
- Select a state to visualise its outgoing flight routes
- Adjust a slider to filter states on their number of airports

### User Interface 
- Multiple screens
- Navigation between different screens
- Interaction buttons
- Dropdown menus
- Search fields

### Software Used 
- Java
- Processing
- ControlP5 library
- CSV data processing

### Concepts Demonstrated 
- Object oriented programming
- ArrayLists and HashMaps
- Reading and processing external datasets
- Data filtering and searching
- Interactive graphical user interfaces
- Data visulation

## How to Run 
1. Install Processing
2. Install the ControlP5 library
3. Download or clone this repository
4. Open the main .pde file in Processing
5. Ensure the required CSV files and images are in the project's data folder
6. Run the sketch
